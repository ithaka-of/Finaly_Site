# ITHAKA — личный сайт Сергея Тимошенко

Сайт-визитка о сайтах, автоматизации и AI-инструментах: `/` — Modern Myth, `/resume` — резюме первым экраном и кейсы ниже, `/play` — мини-игра. `/cases` оставлен как статическая заглушка с редиректом на `/resume` (для старых ссылок).

## Локальный запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

GitHub Actions автоматически публикует ветку `main` через GitHub Pages.
