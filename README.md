# ITHAKA — личный сайт Сергея Тимошенко

Сайт-визитка о сайтах, автоматизации и AI-инструментах: `/` — Modern Myth, `/cases` — кейсы, `/play` — мини-игра.

## Локальный запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

GitHub Actions автоматически публикует ветку `main` через GitHub Pages.
